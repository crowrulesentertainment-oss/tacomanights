# Tacoma Nights

**The City Comes Alive.**

Tacoma Nights is the CrowRules Entertainment community-driven television and storytelling platform, beginning in Tacoma and the South Sound and expanding across the Pacific Northwest and beyond.

The website is published from the root of this standalone repository using GitHub Pages.

- Website: https://crowrulesentertainment-oss.github.io/tacomanights/
- YouTube: https://www.youtube.com/@CrowRules_TV
- CrowRules Entertainment: https://crowrulesentertainment-oss.github.io/crowrulesentertainment/

See `WEBSITE-ROADMAP.md`, `SUPABASE-SETUP.md`, and `ADMIN-SETUP.md` for project documentation.
