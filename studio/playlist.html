YouTube playlists are stored in the existing live_network_playout_queue table as youtube-playlist:// items. The local bridge uses the YouTube embedded player in your OBS/Streamlabs playout browser source. This does not create a separate YouTube livestream or interrupt the current broadcast.

LIVE QUEUE

Programming rundown

Approved, due items are played in scheduled order. Items that need approval stay queued until a producer approves them. Delete removes a single queued item; Clear queued items removes all queued items. Currently playing items are protected.

Sign in to load the programming queue.

HOW PLAYOUT WORKS

One continuous broadcast

  1. Producer adds a video or playlist.
  2. Producer approves it for playout.
  3. The local bridge checks the schedule and queue.
  4. OBS or Streamlabs displays the local playout source.
  5. The YouTube livestream stays active while programming changes.
