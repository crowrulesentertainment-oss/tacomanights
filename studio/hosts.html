Remote Host Control

Create a reusable guest connection for a remote Tacoma Nights host. The host sends video to the room; your encoder receives it through a browser source.

1. Create your host room

VDO.NINJA

Room details are stored only in this browser. Send the host invitation privately.

2. Add the host to your encoder (one-time setup)

  1. Open OBS Studio or Streamlabs Desktop on the broadcast computer.
  2. Open your scene collection and create a scene named Host - Remote.
  3. Add a Browser Source to that scene. Name it Tacoma Nights Remote Host.
  4. Paste the Producer / OBS viewer URL above as the browser source URL. Set width to 1920 and height to 1080; enable audio control if available.
  5. Save the scene. Keep your existing Prerecorded, Standby, and Host - Remote scenes ready.

If you change the room or stream ID, update the browser source URL too. Test the guest before going live.

3. Invite and check in the host

  1. Send the host invitation to the guest. They open it in Chrome or Edge and allow camera and microphone access.
  2. Ask them to use headphones, landscape orientation, stable internet, and a quiet room.
  3. Open the viewer URL in a browser on the broadcast computer to confirm picture and sound before switching scenes.
  4. When ready, use Producer Desk to switch to Host - Remote. The scene switch is controlled locally by OBS/Streamlabs.

This creates the guest links and guides the handoff. The Studio does not yet show a verified guest connection indicator or manage guest permissions through a server-side video room. Do not treat a generated link as proof the guest is connected.
