Producer Desk

The simple on-air workflow: play a recorded segment, bring in a remote host, hand off to another host, then return to the recorded rundown.

Connect the broadcast computer

CHECKING

Sign in with your CrowRules account, then connect the bridge on the computer running OBS or Streamlabs.

On-air handoff controls

These buttons switch to scenes you create in OBS or Streamlabs. Create the scene names exactly as shown before using the buttons.

Simple show sequence

  1. Before the show: connect the bridge, check the correct encoder, confirm all four scenes exist, and test the remote host viewer.
  2. Start with playback: choose Prerecorded when a recorded opener or package is ready.
  3. Host handoff: tell the remote host they are next, confirm camera/audio, then select Remote host on air.
  4. Between hosts: switch to Standby or Main host while the next guest connects; then select Remote host again.
  5. Return to playback: select Prerecorded for the next package. Keep stream start/stop as a separate deliberate action in Master Control.
