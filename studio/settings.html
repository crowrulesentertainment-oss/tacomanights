GET STARTED / SETUP GUIDE

Studio Setup

Follow these steps in order. You only need to do the computer setup once; after that, use Producer Desk for normal shows.

01

Download and install Node.js

Install the current Node.js LTS release (20 or newer) on the computer that runs OBS or Streamlabs.

Download Node.js ↗
02

Download the Tacoma Nights repository

Download the entire repository ZIP, extract it, and keep all folders together. You must have tacomanights/bridge and tacomanights/studio/index.html side by side. Do not download only the bridge folder.

Download project ZIP ↗
03

Create your local settings file

Inside the bridge folder, make a copy of .env.example and name the copy .env. Open .env in Notepad. Do not upload it to GitHub.

Set BRIDGE_TOKEN to a long random value (at least 32 characters), and confirm the Supabase URL and publishable key match the public website configuration.

For OBS: set ACTIVE_ENGINE=obs, OBS_ADDRESS=ws://127.0.0.1:4455, and the OBS WebSocket password. For Streamlabs: set ACTIVE_ENGINE=streamlabs and the local Remote Control URL/token.

04

Install and start the bridge

Open Command Prompt in the bridge folder inside the extracted full repository and run:

npm install
npm start

Leave that window open while producing. You should see the bridge listening on 127.0.0.1:8787.

Test local bridge health ↗
05

Connect your encoder

OBS: open Tools → WebSocket Server Settings, enable the server, use port 4455, and set the password in your local .env.

Streamlabs: open Settings → Remote Control, enable it, open the QR/details view, and copy the local connection URL and token into .env.

Restart the bridge after changing .env.

OBS remote-control guide ↗ · Streamlabs API guide ↗
06

Open the local Studio and pair it

On the broadcast computer, open http://127.0.0.1:8787/studio/. Sign in with the CrowRules account that owns the network data, choose your encoder, and click Connect local bridge. Paste the BRIDGE_TOKEN from .env.

Use the local address above if the GitHub Pages address cannot reach localhost from your browser.

Security — keep these private

  • Never paste the bridge token, OBS password, Streamlabs token, or YouTube stream key into a public page or chat.
  • Never commit .env to GitHub.
  • Keep bridge and encoder control ports bound to localhost. Do not port-forward them to the internet.
  • Only share the remote guest invitation with the intended host.
