Studio Settings

Studio Settings workspace

Install Node.js 20+, copy bridge/.env.example to bridge/.env, configure Supabase and your selected encoder, then run bridge/start-bridge.bat. Open http://127.0.0.1:8787/studio/ on the broadcast computer.

Never upload .env, OBS passwords, Streamlabs tokens, YouTube stream keys or Supabase service-role keys. Keep all control ports bound to localhost.

Operational requirements

  • Use authenticated producer accounts and trusted server-side role checks.
  • Keep privileged operations off the public GitHub Pages client.
  • Record changes in an audit log and provide clear error feedback.
  • Test with separate producer and host accounts before production.
