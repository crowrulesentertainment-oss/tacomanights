Broadcast setup

  1. Add a Browser Source in OBS or Streamlabs.
  2. Use the standard overlay URL, set dimensions to 1920 × 1080.
  3. Keep the source active and visible in the scene; use this control room to show and hide individual graphics.
  4. Realtime must be enabled in Supabase. All graphics browser sources must be connected to the same project.

This graphics control channel is separate from the video playout and YouTube broadcast. Hiding a graphic never stops the livestream. Design files can be exported and loaded as JSON.
