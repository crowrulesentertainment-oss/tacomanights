Set up the remote host graphic

  1. Open Host Control and generate the remote host viewer URL.
  2. In OBS or Streamlabs, open the Host - Remote scene.
  3. Add a Browser Source and paste the viewer URL.
  4. Set the source to 1920 × 1080 and position it to fill the program frame.
  5. Add a separate Text source for the host name and show title. Keep it editable between guests.
  6. Test camera, microphone, and sync before the live handoff.

Lower thirds and overlays

  • Use a consistent safe margin so names are not clipped on televisions or mobile screens.
  • Keep host name, segment title, and Tacoma Nights branding on separate sources where possible.
  • Use a dedicated alert scene for community announcements rather than changing the main camera scene mid-sentence.
  • Keep the prerecorded scene clean so recorded packages are not covered by duplicate lower thirds.

This page provides the scene plan and setup workflow. It does not yet publish or update overlay graphics automatically from the website.
