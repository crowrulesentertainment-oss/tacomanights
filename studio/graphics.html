Install in OBS Studio or Streamlabs

  1. Add a Browser Source to your scene.
  2. Paste one of the graphics URLs above and set width to 1920 and height to 1080.
  3. Place the source above your camera or video source.
  4. Keep the browser source active in the scene. Use SHOW ON AIR and HIDE GRAPHIC in this control room to control connected sources.

Live control uses a Supabase Realtime broadcast channel and the existing public browser-safe configuration. No new database table or service-role key is required. Make sure Realtime is enabled for your Supabase project and the browser sources are connected.
